# DeepFlow

An immersive underwater meditation and education experience inspired by BBC's *Our Planet: Ocean*.

The user explores a 3D underwater world — coral reef, fish. Hidden interactive spots trigger guided meditation exercises and educational content about ocean life. The experience runs in a standard desktop browser and in VR headsets via WebXR.

## TODOS Features

- First-person navigation (WASD + mouse)
- Click on fish → species info card
- Click on glowing orb → box breathing meditation (4-4-4-4 timer)
- One-click VR mode via WebXR
- Ambient ocean audio

## Tech Stack

- **A-Frame 1.5** — 3D scene, WebXR, camera
- **aframe-extras** — WASD movement controls
- **Three.js** — custom animations
